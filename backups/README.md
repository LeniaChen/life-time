# backups

放数据备份的地方。

程序里「设置 → 数据备份 → 备份到 iCloud」生成的 `时光备份-*.txt`
可以定期拷一份到这里，作为离线存档。

## 这些文件不会进 Git

备份里有你每一小时写的具体内容——做了什么、什么时候做的、
自己怎么评价的。这是相当私密的日记级数据。

所以 `.gitignore` 默认排除了这个目录下的所有 `.txt` 和 `.json`，
只保留这份说明。**即使仓库设为私有，也建议保持这个设置。**

如果确实想把某次备份纳入版本管理，手动 `git add -f` 指定文件。

## 恢复

打开备份文件 → 全选复制 → 程序里设置 → 数据备份 → 粘进文本框 →
点「导入」。

导入会整体替换当前数据，所以如果当前还有没备份的新记录，
先备份再导入。
