# life = time

每小时记录一次「刚过去这一小时在做什么」，然后按日 / 周 / 月 / 年
回顾时间去了哪里。

不是为了记账，是为了**警惕每一小时是否过得有意义**。

---

## 它长什么样

- **记录** — 整点弹出，选类别 + 写一句话 + 标一下有意义/一般/虚度
- **时间线** — 按天逐小时回看，空档可原地补填
- **总结** — 日/周/月/年四档，环形图、堆叠柱、时段镶嵌图
- **设置** — 时段、类别、备份、AI 点评

---

## 技术形态

**一个 HTML 文件，没有别的。**

- 零依赖、零构建、零服务器、零外部请求
- 完全离线运行
- 数据存在浏览器本地，备份为明文 JSON
- 约 66 KB，1700 行左右

## 接手这个项目

**先读 [CONTEXT.md](CONTEXT.md)。**

那里面有：为什么是现在这个架构、哪些方案被否决过及原因、实测出来的
平台限制、已知问题、下一步可以做什么。

有一条尤其重要，不知道会丢数据：

> **手机上那个 HTML 的文件名就是数据库的钥匙。**
> 浏览器用文件路径作为存储身份，改名或移动文件 = 读不到旧数据。
> 更新版本必须保持文件名逐字一致。详见 CONTEXT.md 第 5.1 节。
